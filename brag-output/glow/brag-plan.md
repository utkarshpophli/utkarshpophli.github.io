# Brag Plan: GLOW

## What is this app?
GLOW (General Local Offline Windows-agent) is an autonomous, vision-first AI assistant that can see, understand and control a Windows PC through a glowing-orb PyQt6 interface, with 92 tools and a Planner, Executor, Verifier architecture.

## The angle
**One sentence in, a finished file out.** The README's own example prompt ("Look at my screen, analyze this chart, and save a summary to report.txt") is the whole story: GLOW looks, plans, acts, verifies, and the file contains real analysis, not placeholders. The orb is the character; it watches, thinks and then finishes the job.

## Hook (first 2-3 seconds)
A single blue orb breathes in the dark. A light input bar rises and the prompt types itself in, key by key.

## Key moments (the middle)
- The wordmark **GLOW** lands on a bell hit (beat 4.39s) with "General Local Offline Windows-agent".
- Planner, Executor, Verifier light up in order while four README checks tick off one by one, ending in a `report.txt` chip.
- A counter rolls to **92** as the eight tool categories deal in on consecutive beats (15 + 8 + 12 + 13 + 7 + 14 + 13 + 10).

## Outro / punchline
The orb swells back to centre: "Vision-first. Fully autonomous." The models it works with deal in (Groq, Gemini Vision, Claude, OpenAI, Ollama), then `github.com/utkarshpophli/GLOW`.

## User flow worth showing
Entry: type a plain-English request. Key action: Planner, Executor, Verifier run a vision loop (screenshot, analyse, summarise). Result: `report.txt` created with an actual analysis.

## Tone
- Preset: cinematic
- Creative direction: a quiet sci-fi assistant waking up, no jokes
- Interpretation: slow-burn opening, wide empty space around the orb, big type for the reveal, three deliberate sound hits, everything else restrained.

## Format: landscape, 1920x1080
## Duration: 21.28s

## Visual identity (from the project)
- Background: #070B14 to #0B1426 (dark, so the orb reads; the app's overlay is transparent)
- Accent: #4A90E2 (orb and borders in `body/glow_orb.py`), highlight #68AEFF, success green #51CF66 and alert red #E74C3C/#FF6B6B (the README diagrams)
- Text: #F8F9FA on dark; the input box is #F8F9FA with #2C3E50 text, as in the app
- Display font: Segoe UI (the app's font)
- Body font: Segoe UI; Consolas for filenames
- Strongest visual element: the glowing orb and the light rounded input box

## Share copy (draft)

## Audio direction
- Role: cinematic support
- Music: `happy-beats-business-moves-vol-12-by-ende-dot-app.mp3`, 109.96 BPM
- Music treatment: starts at 0, volume 0.30, fade in 0.8s, fade out over the last 1.4s
- Music cue guidance: bundled preset read. Strong cues locked: 4.39s (GLOW reveal, beat), 13.11s (tools section starts), 17.47s (outro starts). Beat grid for the eight category chips: 13.11, 13.64, 14.20, 14.73, 15.29, 15.84, 16.38, 16.93.
- Audio-reactive treatment: subtle; music loudness breathes the orb's glow. No waveform or equalizer visuals.
- SFX posture: sparse, three big hits (reveal bell, tools transition, outro bell) plus keypresses while typing and small selection ticks on the checks
- Audio-coupled moments: typed prompt with randomised keypresses; four checks with a selection tick each; eight chips with a stacking tick each
- Restraint rule: no sound on text that is only fading in; nothing louder than the music bed except the three hits

## Storyboard

### Scene 1 - Hook - 4.39s
Dark stage, the orb breathing. At 0.9s a light input bar slides up. The prompt "Look at my screen, analyze this chart, and save a summary to report.txt" types from 1.2s to 3.5s, then holds.
Sequential/interaction: yes, typed text.
Audio intent: hushed and focused, keypresses only.
Transition mood: hard cut on the beat -> Scene 2

### Scene 2 - Reveal - 4.35s
The orb rises and **GLOW** lands at 4.39s. Subtitle "General Local Offline Windows-agent" at 5.0s. Line "It can see, understand, and control your Windows PC." at 5.9s, held to the end of the scene.
Sequential/interaction: none (three staged text entries).
Audio intent: one deep bell on the reveal.
Transition mood: soft -> Scene 3

### Scene 3 - The flow - 4.37s
The orb shrinks to the corner. Planner, Executor, Verifier light up left to right. A chart window is scanned by a vision sweep. Four checks appear every 0.7s: "Takes screenshot with Gemini Vision", "Analyzes chart data and trends", "Summarizes key findings with AI", "Creates file with actual analysis (not placeholders!)". A `report.txt` chip lands at the end. Hold of at least 1.5s with all four visible.
Sequential/interaction: yes, four checks one by one, each held until the scene ends.
Audio intent: small, clean selection ticks, bright bell on the file chip.
Transition mood: hard cut on strong cue 13.11s -> Scene 4

### Scene 4 - 92 tools - 4.36s
Big counter rolls to **92**. Eight chips deal in on consecutive beats: File & OS 15, Browser 8, Office 12, AI-Powered 13, Vision 7, System 14, Dev Tools 13, Input 10. The counter shows the running total. Caption: "Comprehensive Windows automation".
Sequential/interaction: yes, eight chips one per beat (labels are 2-3 words, they stay on screen).
Audio intent: stacking ticks rising in density, then silence before the outro.
Transition mood: dramatic -> Scene 5

### Scene 5 - Outro - 3.81s
Orb grows back to centre on strong cue 17.47s. "Vision-first. Fully autonomous." Model chips deal in: Groq, Gemini Vision, Claude, OpenAI, Ollama. Final line `github.com/utkarshpophli/GLOW`. Fade to dark with the music.
Sequential/interaction: yes, five model chips.
Audio intent: resolving bell, then a clean fade.
Transition mood: fade to black.
